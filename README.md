# ResumeSense

**ResumeSense** is an AI-powered resume analysis and interview preparation platform that helps job seekers evaluate their resumes against a specific job description. The application identifies skill gaps, generates personalized interview questions, and creates a structured preparation roadmap to improve interview readiness.

---

## Features

- Upload Resume (PDF)
- Upload Job Description
- AI-powered Resume Analysis
- Skill Gap Detection
- Personalized Interview Question Generation
- Custom Interview Preparation Plan
- Secure User Authentication
- Clean and Responsive User Interface

---

## How It Works

1. Create an account or log in.
2. Upload your resume in PDF format.
3. Paste or upload the job description.
4. The AI analyzes your resume against the job requirements.
5. Receive:
   - Resume analysis
   - Missing skills
   - Personalized interview questions
   - Step-by-step preparation roadmap
